# ARぬりえ（AR coloring web app）

ぬりえの紙に印刷したQRをカメラで読み、**紙の上に絵が「浮き出して」動き回る**Webアプリ。
QuiverVision 系の「ぬりえAR」を、外部ライブラリ最小・サーバ不要（静的ファイルのみ）で作ったもの。

- 紙の上に描いた線と**同じ形**のキャラクターを、カメラ映像の上に射影変換して重ねる
- 紙に塗った**色をその場で採取**して、動くキャラの色に使う（赤く塗れば赤い魚が泳ぐ）
- QRの4隅から平面のホモグラフィを推定するので、**紙を斜めから映しても紙に貼り付いたまま**動く
- 追従は「全画面サーチ → QR周辺だけ切り出して追跡」の2段構え（CPU負荷を抑える）

## いま入っているもの

| ファイル | 役割 |
|---|---|
| `web/index.html` | ARアプリ本体（カメラ・QR検出・射影・描画） |
| `web/art.js` | **絵の形の唯一の定義**（印刷ページとARの両方がこれを使う） |
| `web/print.html` | 印刷用のぬりえ（A4）。QRもここで生成 |
| `web/jsQR.js` | QRデコーダ（vendored, MIT） |
| `web/qrcodegen.js` | QR生成（vendored, MIT） |
| `ARぬりえ_さかな_A4.pdf` | 印刷用PDF（A4実寸）・さかな |
| `ARぬりえ_くるま_A4.pdf` | 印刷用PDF（A4実寸）・くるま |
| `tools/make_test_photo.py` | 検証用の「カメラ写真」合成（塗り→斜め撮影風） |

## 用紙は2種類（QRの中身で自動判別）

| QR | 用紙 | 印刷URL |
|---|---|---|
| `ARNURI-01` | さかな | `print.html?art=ARNURI-01` |
| `ARNURI-02` | くるま | `print.html?art=ARNURI-02` |

アプリのURLは1つ。印刷した紙のQRを読むだけで、さかな／くるまが切り替わる。

## 使い方

1. 印刷したい用紙のPDFをA4・実寸100%で印刷
2. スマホで公開URLを開く（**HTTPS必須**。カメラはセキュアコンテキストでしか使えない）
3. 「カメラをはじめる」→ 紙全体が画面に入るように映す
4. 魚が泳ぎだす。紙を傾けても魚は紙に貼り付いたまま

ローカルで試す:

```bash
./serve.sh          # http://localhost:8117 + 公開HTTPS URL を発行
```

カメラ無しで挙動を確認する（合成写真モード）:

```
http://localhost:8117/index.html?img=test/photo_tilted.jpg&debug=1
```

`?img=` には画像でも動画(.mp4)でも渡せる。`&debug=1` で fps / QRデコード時間 / 検出四隅を表示。

## しくみ

1. **QR**（用紙右下 30mm、`ARNURI-01`）を `jsQR` で読む
2. QRの4隅（画像座標）↔ 紙面上の既知の矩形（mm座標）で **3x3 ホモグラフィ**を解く
3. 紙面mm座標で描いたキャラの各頂点を、そのホモグラフィで画像座標へ射影して塗る
   → ベジェを使わず多角形に落としてあるので、**遠近歪みまで正確**に紙へ貼り付く
4. 同じホモグラフィの逆写像で、紙の「体・尾・ひれ」の領域の画素を平均 → 塗り色を採取
   （白い紙と鉛筆線は彩度・明度で除外。未塗装なら既定色）
5. 位置・回転・尾びれ・体のくねりは紙面座標のアニメなので、カメラが動いても紙に固定される

## 検証したこと

合成した「カメラ写真」（まっすぐ／強めの斜め／遠景）で:

- 検出: まっすぐ・斜め ともに追従（追跡時 約2ms/フレーム、60fps維持）
- 色採取: 赤(222,74,44)→(183,76,77)、黄(240,172,40)→(248,167,15)、青(62,150,198)→(53,143,195)
- 白紙（未塗装）: 採取は棄却され既定色（オレンジ／黄）で描画
- 遠景（紙が画面の約40%）: QRが小さすぎて**検出できない**（→ 近づけば可）

## 未確認・制約

- **実機のスマホカメラでは未検証**（合成写真のみ）。手ブレ・照明・ピントの影響は未評価
- 紙に印刷された魚は消えないので、ARの魚と重なる瞬間がある（動きで主役は分かる）
- 遠景ではQRが読めない。QRを36mmにする／画面いっぱいに映す誘導を強めるのが次の手
- 公開URLはトンネル（localhost.run）なので**一時的**。常設するなら `microsplit.me` に
  `nurie.microsplit.me` を足して cloudflared の ingress に `http://localhost:8117` を追加（要 root＋DNS）
- 紙は1種類（さかな）だけ。車・ロケット等を足すときは `art.js` に形を追加し、
  `SHEET.qr.text` を用紙ごとに変えれば、QRで用紙を判別して出し分けられる
